# CSS Simplified
 
My notes, demos and small projects from Web Dev Simplified's *CSS Simplified* course, done in April 2026. Lesson folders are numbered to match the course, and most have their own `index.html` and `style.css`.
 
## Modules
 
| Module | Topics |
| --- | --- |
| [01 Basics](Module%2001%20-%20Basics) | Selectors, inheritance, colours, specificity, pseudo-classes, units (px, %, viewport, rem, em) |
| [02 Display Properties](Module%2002%20-%20Display%20Properties) | Normal flow, floats, Flexbox, Grid, positioning (relative, absolute, fixed, sticky) |
| [03 Advanced Concepts](Module%2003%20-%20Advanced%20Concepts) | CSS variables, advanced selectors, pseudo-elements, margins, normalise vs reset, media queries, custom fonts |
| [04 Animations](Module%2004%20-%20Animations) | Transitions, transforms, keyframe animations, perspective |
| [05 New Features in CSS](Module%2005%20-%20New%20Features%20in%20CSS) | `corner-shape` |
 
## Projects
 
- **Modal** (Module 2)
- **Pinterest-style gallery** with CSS Grid and multi-column layout (Module 2)
- **Transition buttons**, an **animated button** and a **loading button** (Module 4)
- **3D cube** with transforms and perspective (Module 4)
## Running it
 
Open any lesson's `index.html` in a browser. No build step needed.
